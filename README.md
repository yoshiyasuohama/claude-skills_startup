# claude-skills_startup

スタートアップの名著・文献・資料を **Claude Skill** 化して配布するリポジトリです。
起業家、学生起業家、スタートアップ支援者が、Claudeとの対話の中で名著のフレームワークや考え方をすぐに使えるようにすることを目的としています。

スタートアップに関する名著は数多くありますが、「読んで理解する」ことと「自分の事業に当てはめて使う」ことの間には大きな距離があります。本を読み終えたあと、いざ自分のアイデアに適用しようとすると、何から手をつければよいか分からなくなる。そんな経験を持つ人は少なくないはずです。

このリポジトリは、その距離を埋めるためのものです。名著に書かれたメソッドやノウハウを、Claudeが一緒に手を動かしてくれる「実行できる形」に変換して届けます。

## Claudeへのスキル登録方法

### 登録する

1. Claudeのホーム画面から「カスタマイズ」を選択します
2. カスタマイズ画面が表示されたら、右上の「追加」をクリックします
3. 「Skillsをアップロード」を選択します
4. 該当スキルを参照するか、ドラッグアンドドロップします
5. 「アップロード」をクリックすると、登録完了です

### 実行する

1. チャット欄に「/（スラッシュ）」を入力します
2. 登録したスキルの候補が表示されるので、実行するスキルを選択します

スキルが表示されない場合は、スラッシュの後にスキル名を入力してください（例：`/method-the-mom-test`）。

## このリポジトリでできること

- スタートアップの名著・文献・資料のメソッド・ノウハウを、Claude上で実行できるSkillとして利用できます
- Skillを実行するだけで、Claudeが質問を投げかけながらハンズオン形式で入力を進め、名著のフレームワークに沿った結果を出力します。最初に依頼文を考える必要はありません
- 本を読んでいなくても、フレームワークの要点を体験しながら理解できます。すでに読んだ人にとっては、内容を自分の事業に落とし込む実践の場になります
- 出力された結果は、事業計画の整理、ピッチ資料の下書き、チームでの議論のたたき台としてそのまま活用できます

## Skillの特徴

### 1. 依頼文を考えなくていい

一般的なAIとの対話では、「何をどう頼むか」をユーザー自身が考える必要があります。このリポジトリのSkillは、実行するとClaudeの側から進め方を提示し、必要な情報を順番に尋ねてくれます。プロンプトの書き方を知らなくても、最後までたどり着けます。

### 2. 1問ずつ、ハンズオン形式で進む

質問は一度に1つずつ投げかけられます。回答するたびに、その内容がフレームワークのどこに当たるのかをClaudeが短くフィードバックするため、考えを整理しながら次のステップへ進めます。

### 3. 名著のフレームワークに沿った結果が手元に残る

すべての質問に答え終えると、名著のフレームワークに沿った形で結果がまとめて出力されます。あわせて、次に取るべきアクションも提案されるため、対話のあとすぐに行動へ移せます。

### 4. 1冊＝1Skillのシンプルな構成

各Skillは1冊（1資料）に対応しており、目的に応じて必要なものだけを選んで使えます。複数のSkillを順番に実行すれば、異なる名著の視点から同じ事業を多角的に見直すことも可能です。

## 体験の流れ

```
① Skillを実行する
   ↓
② Claudeが、このSkillでできることと進め方を説明する
   ↓
③ Claudeからの質問に1問ずつ答える
   （回答ごとに、フレームワーク上の位置づけをフィードバック）
   ↓
④ 名著のフレームワークに沿った結果が出力される
   ↓
⑤ 次に取るべきアクションが提案される
```

所要時間はSkillによって異なりますが、多くは15〜30分程度で一通りの結果が得られる設計を目指しています。
